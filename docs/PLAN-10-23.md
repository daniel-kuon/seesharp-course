# Plan for levels 10–23

Specification for the book chapters SeeSharp does not cover yet. **No exercise folders exist for
these levels**; this file plus the 288 new entries in `skills.yaml` are the contract the content
authors work from. Structure, ids and `teaches`/`requires` follow `SKILL-MODEL.md` (tool repo) and
`docs/SKILLS.md`; the level ladder, elective table and deviations come from `docs/MODULE-MAP.md`.

## Conventions

- **Published order** is the folder order: `10-kollektionen` … `15-dateiverarbeitung` (core), then
  the electives `16-…` … `23-…`. A level unlocks from the union of its exercises' `requires`.
- **Exercise folders** `01-…` … `07-…` are mandatory; `10-…` … `12-…` are `optional: true`
  (Zusatzaufgaben). Optional exercises only re-teach skills a mandatory exercise teaches and only
  require skills taught by mandatory exercises.
- **Ids**: module ids and exercise ids match `^[a-z0-9][a-z0-9-]*$` and are unique across the course;
  exercise ids carry a short module prefix (`kollektionen-`, `ausnahmen-`, `delegaten-`, `linq-`,
  `fortgeschritten-`, `dateien-`, `attribute-`, `threads-`, `adonet-`, `efcore-`, `wpf-`, `netz-`,
  `aspnet-`, `publish-`).
- **Reading**: section number, German section title and the *verified printed page*; physical page
  = printed + 32. Pages were taken from the body text (the TOC is stale in chapters 4, 17, 18, 20). Where
  the book does not cover a topic (e.g. `CountBy`, `PropertyInfo.Invoke`), the exercise says so and the
  summary has to supplement it.
- **Types**: `coding` (starter + tests; may contain quiz items), `quiz` (multiple choice / open),
  `review` (supervisor-graded, source captured into the export bundle).
- **Sample** = the project under `SeeSharp\samples\` that serves as the model answer (path relative to
  `samples/`); `NEW` = written from nothing. Most samples print instead of returning, so logic has to be
  lifted into testable methods (INVENTORY.md §3).
- **Book exercise** = the exercise from INVENTORY.md §4 the task covers (chapters 19–23 have none).
- **Determinism**: no wall-clock timing and no `Thread.Sleep` in any assertion; file work happens in a
  temp directory per test whose path contains a space, an umlaut and a comma; random input is seeded;
  network tests use a stub `HttpMessageHandler` or `127.0.0.1` with port 0.
- **Electives** require only core skills (levels 0–15) plus skills taught by earlier exercises of the
  *same* elective, never another elective's skills. Where an elective needs a concept that is
  elsewhere an elective (e.g. `await` in `21-netzwerk`, EF without `async`), it either avoids it or teaches
  its own, differently named skill (`net.await-io`).

## Level 10 — Kollektionen: Listen, Mengen, Wörterbücher

- **Folder**: `modules/10-kollektionen/` (core)
- **Module id**: `kollektionen`
- **Titel (de)**: Kollektionen: Listen, Mengen, Wörterbücher
- **Reading**: book chapter 11, *Kollektionen*, printed page 691 (physical 723)

**Summary outline** (`summary.de.md`, 400–800 words):

- Arrays haben feste Größe; Kollektionen wachsen und bieten Suchen, Einfügen und Entfernen (11.1, S. 691). Alle generischen Kollektionen implementieren `IEnumerable<T>` und `ICollection<T>` (11.2).
- Kollektionsinitialisierer und Kollektionsausdrücke `[1, 2, ..rest]` mit Spread-Element (11.3, S. 695).
- `List<T>` (Array-Unterbau): Add/Insert/Remove, Indexer, Sort, ToArray; Elemente nie in `foreach` entfernen (11.4.1, S. 697). `Queue<T>` (FIFO) und `Stack<T>` (LIFO) als Spezialisierungen, `LinkedList<T>` mit Knoten (11.4.2, S. 700).
- Mengen: `ISet<T>`, `HashSet<T>` mit Hashtabelle; der Elementtyp braucht passendes `Equals()`/`GetHashCode()` (11.5.2, S. 704); Mengenoperationen Union/Intersect/Except.
- `SortedSet<T>` (balancierter Binärbaum): sortiert, ohne Duplikate, Min/Max/GetViewBetween (11.5.3, S. 711).
- `Dictionary<TKey,TValue>`: Indexer, `TryGetValue`, Aufzählung von `KeyValuePair`, Gruppieren mit `Dictionary<K, List<V>>` (11.6, S. 714).
- Schreibgeschützte Sichten (`AsReadOnly`, `IReadOnlyList<T>`) versus unveränderliche Kollektionen (`ImmutableList<T>`, 11.7, S. 716).
- Die richtige Kollektion nach Anforderung wählen: `Contains()` ist in List O(n), in HashSet O(1) (11.8/1, S. 723).

Class library `Listen` with static class `Listenwerkzeuge` (starter: signatures with `throw new NotImplementedException()`). `RemoveEvens(List<int>)` removes all even numbers in place; the tests use lists with consecutive evens so that a naive `foreach` removal or a forward `for` loop fails. `InsertSorted(List<int> aufsteigend, int wert)` keeps the list ascending using `IndexOf`/`Insert` (or a scan). `MoveToFront(List<string>, string)` moves an existing entry to index 0, inserts it if missing, and never duplicates it (`Contains`, `IndexOf`, `RemoveAt`, `Insert`). `Top3(List<int>)` returns a NEW list with the three largest values in descending order and must not change its argument (copy, `Sort`, `Reverse`, `GetRange`). `Rotate(int[] a, int k)` returns a new array rotated left by k (use `ToList`/`List<int>(a)`, `RemoveAt`/`Add`, `ToArray`). (the exception is only described, `InvalidOperationException` is taught in level 11).

## Level 13 — LINQ-to-Objects

- **Folder**: `modules/13-linq/` (core)

- **Titel (de)**: LINQ-to-Objects
- **Reading**: book chapter 18, *LINQ-to-Objects*, printed page 1209 (physical 1241)

**Summary outline** (`summary.de.md`, 400–800 words):

- LINQ ist eine Sammlung von Erweiterungsmethoden auf `IEnumerable<T>` (`System.Linq.Enumerable`) mit Lambda-Ausdrücken als eingespritzter Funktionalität; Methoden lassen sich als Fluent-API verketten (18.1/18.2.1–18.2.3, S. 1209–1213).
- Zurückgestellte versus sofortige Ausführung: eine Abfrage läuft erst bei Aufzählung bzw. bei `ToList()`/`ToArray()`/Aggregaten (18.2.4, S. 1215).
- Filtern, Sortieren, Projizieren: `Where`, `OrderBy`/`ThenBy`, `Select`, `SelectMany` (18.2.6–18.2.8, S. 1217–1222).
- Gruppieren und Verknüpfen: `GroupBy`, `Join`, `GroupJoin`, `Zip` (18.2.9–18.2.10, S. 1222–1228); weitere Operatoren: Quantoren, Elementoperatoren, Mengenoperatoren, Aggregate, `Take`/`Skip`/`Chunk` (18.2.11, S. 1228).
- Abfragesyntax `from … where … orderby … select`, `group … by`, `join`, `let` und Folgeabfragen mit `into` (18.3, S. 1235–1243); die Abfragesyntax wird vom Compiler in Methodenaufrufe übersetzt.
- Unterabfragen (18.4, S. 1244). PLINQ (18.5) gehört zum Wahlmodul Multithreading.
- Hinweis: Kapitel 18 ist auf dem Stand C# 12 / .NET 8; `CountBy`, `AggregateBy` und `Index` (ab .NET 9) stehen nicht im Buch und werden in der Zusammenfassung ergänzt.
