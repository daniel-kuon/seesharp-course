# Comprehension questions

This quiz checks whether you can not only operate the toolchain but also explain it. If needed, re-read in the book **3.1.1 Installing** (page 61), **3.1.2 Creating a project with the CLI** (page 65), **3.1.4 Compiling source code to IL** (page 71), **3.1.5 Running** (page 74) and **3.1.6 Program errors** (page 76).

For the questions with code, work out the answer by running the code in your head; only afterwards try it in Rider. The multiple-choice questions have exactly one correct answer. The AI tutor judges the open answers (it gives you one round of corrections), after which your supervisor reviews everything.
