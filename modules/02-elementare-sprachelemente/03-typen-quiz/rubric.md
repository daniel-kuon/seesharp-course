# Rubrik — Variablen-Quiz (nur für die Betreuung)

- Frage `implizit`: Die Feinheit mit konstanten Literalen (`char c = 65;`
  kompiliert, `char c = i;` nicht) nur ansprechen, wenn der Trainee danach
  fragt.
- Praktische Nachfrage: In Rider `var` auf einen Ausdruck setzen und mit dem
  Mauszeiger den abgeleiteten Typ anzeigen lassen.
