# Rubrik — Variablen-Quiz (nur für die Betreuung)

- Frage `implizit`: Anders als bei `byte b = 65;` gibt es für `char` keine
  implizite Umwandlung konstanter `int`-Werte: `char c = 65;` meldet CS0266,
  nötig ist `(char)65`. Nur ansprechen, wenn der Trainee danach fragt.
- Praktische Nachfrage: In Rider `var` auf einen Ausdruck setzen und mit dem
  Mauszeiger den abgeleiteten Typ anzeigen lassen.
