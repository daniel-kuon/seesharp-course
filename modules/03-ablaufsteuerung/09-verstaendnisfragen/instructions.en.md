# Comprehension questions

This quiz checks whether you can not only write branches, loops and Euclid's algorithm but also explain them and trace them in your head. If needed, re-read in the book **4.7.2 Conditional statements and case statements** (page 253), **4.7.3 Loops** (page 270), **4.7.3.6 Terminating loops early** (page 278), **4.7.4 Exercises** (page 281) and **4.6 Overflow** (page 244).

For the questions with code, run the code in your head, ideally with a small table of values; only afterwards try it in Rider or in the debugger. The multiple-choice questions have exactly one correct answer. The AI tutor judges the open answers (it gives you one round of corrections), after which your supervisor reviews everything.
