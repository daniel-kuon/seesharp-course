# Comprehension questions

This quiz checks whether you can not only write the class `Bruch` and its building blocks but also explain them: properties, constructors, overloading, references, static members, recursion and overloaded operators. If needed, re-read in the book **5.2 Instance variables** (page 300), **5.3.5 Overloading methods** (page 334), **5.4.3 Preparing for use (constructors)** (page 340), **5.5 Properties** (page 361), **5.8 Static members** (page 373), **5.9.2 Recursive methods** (page 382) and **5.9.3 Overloading operators** (page 385).

For the questions with code, run the code in your head; only afterwards try it in Rider. The multiple-choice questions have exactly one correct answer. The AI tutor judges the open answers (it gives you one round of corrections), after which your supervisor reviews everything.
