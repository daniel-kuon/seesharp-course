# Comprehension questions

This quiz checks whether you can not only write the interplay of several classes but also explain it: aggregation, `ToString()`, nested classes, indexers, access levels and class libraries. If needed, re-read in the book **5.10 Aggregation or composition** (page 388), **5.11 Nested classes** (page 391), **5.12 Indexers** (page 393), **5.13 Access levels** (page 398), **7.16 Exercises**, exercise 5 on `ToString()` (page 588), and **5.15 Exercises**, exercise 4 on vectors (page 425).

For the questions with code, run the code in your head; only afterwards try it in Rider. The multiple-choice questions have exactly one correct answer. The AI tutor judges the open answers (it gives you one round of corrections), after which your supervisor reviews everything.
