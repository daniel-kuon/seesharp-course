# Overloading, Hiding, Overriding (Quiz)

Read section **7.6, “Hiding Heirlooms Using Specialized Variants”** (page 555), along with 7.6.1 (Methods, page 555), 7.6.1.2 (Variants and Pitfalls, page 557), and 7.6.2 (Fields, page 561). Exercise 3 in **7.16** (page 587) asks for the three terms.

The sample projects `Methoden ausblenden/*` and `Felder ausblenden` in the book’s Sample folder are small; type them into a console project and try out each question before you answer. However, your answers should come from an understanding of the concept: Which type determines the behavior—the static type of the variable or the dynamic type of the object?
