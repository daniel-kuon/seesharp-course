# Interfaces Quiz: Declaration, Abstract Classes, Variance

Read Section **9.1, “Defining Interfaces”** (page 614), including 9.1.1.2 (concrete interface members, page 616), **9.1.5 Covariance and Contravariance** (page 634) along with 9.1.5.1 and 9.1.5.2 (pages 637 and 638), as well as Exercise 2 in **9.6** (page 655).

The variance questions refer to the sample projects `Typformalparameter in generischen Interfaces/{Kovarianz, Kontravarianz, Invarianz}` in the book’s sample folder. Read the three `Program.cs` files, then answer the questions based on the rule: `out` for types that are only outbound, `in` for types that are only inbound.
