# Comprehension questions: Delegates and Events

This quiz checks whether you can explain the ideas behind delegates, lambdas, and events and read unfamiliar code. If needed, re-read **10.1.1 Defining Delegate Types** (page 659), **10.1.3 Combining Delegate Objects** (page 663), **10.1.5 Anonymous Functions** (page 665), and **10.2 Events** (from page 678, especially 10.2.3 on page 684).

For the "What does this code do?" questions, say what is printed before you run anything, and give your reasons; feel free to try it out afterwards. Open answers are judged first by the AI tutor (one correction round); the supervisor then reviews them with you.
