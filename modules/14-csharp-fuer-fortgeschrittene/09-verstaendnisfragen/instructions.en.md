# Comprehension questions: C# for Advanced Users

This quiz checks whether you can explain null safety, pattern matching, and spans and read unfamiliar code. If needed, re-read **15.1 Avoiding null reference exceptions** (page 949, especially 15.1.2 on page 953 and 15.1.5 on page 968), **15.2 Pattern Matching** (page 971, especially 15.2.9 on page 984 and 15.2.10 on page 985), **15.3 Methods with ref variables and ref return values** (page 988), **15.4 Span<T> and ReadOnlySpan<T>** (page 991), and **15.6 Series Parameters with Collection Types** (page 1008).

For the "What does this code do?" questions, say what is printed before you run anything, and give your reasons; feel free to try it out afterwards. Open answers are judged first by the AI tutor (one correction round); the supervisor then reviews them with you.
