# Comprehension questions: File Processing

This quiz checks whether you can explain data streams, resource release, and JSON and read unfamiliar code. If needed, re-read **16.1 Data Streams of Bytes** (page 1013), **16.2 Releasing Resources** (page 1026, especially 16.2.3 on page 1027), **16.3 Binary and Text** (page 1032), **16.4 Small Files** (page 1041), and **16.5 JSON** (page 1043), as well as **5.4.5 Cleaning Up Unneeded Objects** (page 355).

For the "What does this code do?" questions, say what is printed before you run anything, and give your reasons; feel free to try it out afterwards. Open answers are judged first by the AI tutor (one correction round); the supervisor then reviews them with you.
