Read section **22.2**, **“Configuring the Request Pipeline and Starting the Application via Program.cs”** (page 1552), along with the middleware components in section 22.2.2 (page 1553), **22.5.3 Handling HTTP Requests** (page 1566), **22.5.4 Statelessness of the HTTP Protocol** (page 1571), and **22.8.7 Overposting** (page 1606).
