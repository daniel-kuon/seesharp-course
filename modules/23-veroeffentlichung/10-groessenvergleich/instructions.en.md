# Extra: Size Comparison

Repeat **23.1.5 Deployment Mode** (page 1644): framework-dependent and standalone.

Publish a small console program in both modes and document the following:

- Which files should be on a computer with the .NET runtime installed,
- which runs on a computer without a runtime,
- how large both folders are (number of files and total size),
- when you choose which option.

The support team will verify your information against the actual issue. There are no tests.
