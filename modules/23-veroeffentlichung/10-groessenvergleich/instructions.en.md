# Extra: Size Comparison

Review **23.1.5 Deployment Mode** (page 1644): framework-dependent and self-contained.

Publish a small console program in both modes and document the following:

- which files belong on a computer with the .NET runtime installed,
- which belong on a computer without a runtime,
- how large both folders are (number of files and total size),
- when you choose which option.

The supervisor checks your information against the actual output. There are no tests.
